## 6. Core Theme

- **Theme**: 「AIが軍隊を地図の上に配備したら、"見えない戦争"が始まった ── v2の緊張度メカニクスが生んだ、砲火なき台湾海峡危機」

- **Core Question**: 「AIに軍事配備の自由を与えたとき、戦争なしでどこまで緊張がエスカレートし、各国の運命はどう変わるのか？」

- **Justification**:
  1. **企画書のSランク要素を全網羅**: 戦略マップ（配備の可視化）、戦術軍事配備（intimidation/show_of_force）、緊張度メカニクス（Rally効果による支持率逆転）の3つがすべてこのテーマに集約される
  2. **Surprise（意外性）**: 中国のintimidationがRally効果で自国支持率を上げるという「脅せば脅すほど相手が強くなる」逆説。さらに中国の国家債務1,187%という破滅的数字
  3. **Drama（ドラマ性）**: 一発も弾を撃たずに台湾海峡が緊張し、各国AIが配備を通じて「見えない戦争」を展開する様は、現実の2026年の台湾海峡情勢と重なる
  4. **Educational（教育的価値）**: Mueller/Schultz/Fearonの学術理論が実際に動いている様子を可視化できる。Richardsonモデルの「経済的疲弊」も体感できる
  5. **Empathy（共感）**: 「戦争を選ばなかったAI」たちが、それでも緊張を高め合う構図は視聴者に「抑止力とは何か」を考えさせる
